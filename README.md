# Portfolio — Rémy Cao

Monteur vidéo & cadreur. Site statique (HTML/CSS/JS), hébergé sur GitHub Pages.

- `index.html` : tout le site
- `thumbs/` : miniatures des projets
- `posters/` : affiches en haute définition
- `reel-loop.mp4` : extrait muet du showreel pour le hero

Pour ajouter un projet : ajoute une ligne dans le tableau `P` de `index.html` et une miniature dans `thumbs/`.
